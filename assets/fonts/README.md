# Fuentes

Instancias estáticas generadas desde las fuentes variables de Google Fonts
(licencia SIL Open Font License 1.1), solo para la imagen Open Graph: satori no
aplica ejes variables, así que cada peso tiene que ser su propio fichero.

| Fichero                    | Origen                                    | Instancia         |
| -------------------------- | ----------------------------------------- | ----------------- |
| `InstrumentSans-Bold.ttf`  | google/fonts · ofl/instrumentsans         | wght 700, wdth 100|
| `Inter-Regular.ttf`        | google/fonts · ofl/inter                  | wght 400, opsz 14 |
| `Inter-SemiBold.ttf`       | google/fonts · ofl/inter                  | wght 600, opsz 14 |

El sitio en sí carga estas familias por `next/font/google`, no desde aquí.
